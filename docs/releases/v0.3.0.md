# ClipCraft 0.3.0

Share clips to Discord in one drag, record each program's sound on its own track, and a recorder
that looks after your computer. Windows now has a setup program and a portable zip, and the command
line tool is its own release.

## What's new

- **Drag a clip into Discord.** Drag a card from the library (or use **Drag into Discord** on the
  clip page) into a chat. A clip bigger than the size you chose (10, 25, 50 or 500 MB) is first made
  into a smaller copy, which starts when you rest the pointer on it, so the drag is instant.
  **Copy file** puts the clip itself on the clipboard. Windows and Linux (X11).
- **Sound mixer.** Settings → Audio → Applications records the game, Discord, a music player or any
  program on a track of its own, each with its own level and a live meter. Picked up when it starts
  playing. Windows 10 (2004 or newer) and Linux (PulseAudio or PipeWire with `pactl` and `parec`).
- **Automatic quality.** When the computer cannot keep up, ClipCraft records every second, then
  every third picture instead of dropping them at random, without touching the size, bitrate or your
  replay. It also steps down early when a game starts taking the computer, and goes back when there
  is room.
- **Protects your computer.** A watchdog lightens and, if needed, stops clipping if ClipCraft uses
  nearly all of the processor for a long time or far too much memory. Exports use half the cores at
  lower priority. Settings → Video → *Protect my computer* (on by default).
- **Pause and resume** by hotkey or button, with no frozen gap in the clip.
- **Black-window rescue.** If a game window gives only black, capture switches to the screen in the
  same recording and tries the window again later.
- **One buffer through a window loss.** When a game's window closes and capture moves to the desktop,
  the same replay and sound carry on.
- **Restart the replay after each save** (optional), so clips never repeat footage.
- **Rename clips** (F2, right-click or CLI), **clip-length shortcuts** (for example Shift + F8 for
  the last 2 minutes), exports that fit their size target, and 50 MB and 500 MB share presets.
- **Quiet by default.** New setups start with sound effects and the save pop-up off, and the setup
  offers to start ClipCraft quietly in the tray when you sign in. Updates never install while you
  are clipping.
- **New sound effects** and the ClipCraft icon on the Windows program, the setup and the Linux
  taskbar.
- **Signed updates are ready** (switched on by a release key; not yet set).

## Downloads

- **Windows:** `ClipCraft-Setup-0.3.0.exe` (installs for your user, Start menu links, uninstaller)
  or `clipcraft-0.3.0-windows-x86_64-portable.zip` (portable: unzip anywhere and run `bin\clipcraft.exe`).
- **Linux:** `clipcraft-0.3.0-linux-x86_64.tar.gz`.
- **Command line tool:** its own release, `cli-v0.3.0`.

## Important limits

- The Windows per-program sound, the Windows drag into Discord, Copy file, and the pause,
  black-window rescue and automatic-quality changes were tested on Linux and with generated
  pictures and sound, not yet with real games on Windows. Please report what you see.
- Drag into Discord needs X11 on Linux; on Wayland and macOS use Copy file.
- Downloads are unsigned. Windows may show a SmartScreen warning. Check downloads against each
  release's SHA256SUMS.txt.

No media, logs, screenshots, or bug reports are uploaded automatically.
