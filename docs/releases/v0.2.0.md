# ClipCraft 0.2.0 — early release candidate

ClipCraft is a Rust desktop clip recorder and lightweight editor. Capture, library, playback,
editing, and export work locally without a ClipCraft account or hosted server.

## Highlights

- Save recent gameplay or desktop recording to your local library with a shortcut. Game-only
  capture, timed desktop fallback, and continuous desktop capture are configurable.
- See available replay time and a warning when changing source or encoder clears the buffer.
  A game closing or crashing does not automatically save a clip.
- Browse and organize clips by game, search, play, trim, and export. The small editor supports
  cuts, rearrangement, text, fades, and basic effects.
- Record system and microphone audio, with optional local noise suppression and a microphone test.
- Prepare and review a bug report locally; copying it and opening GitHub are separate actions.
- On Wayland, request global shortcuts through the desktop portal; direct keyboard-device access
  is a separate opt-in fallback. Portal behavior on real desktops is still unverified.
- The Windows download uses a local per-user installer. Linux has a tarball; CLI downloads are separate.

## Important limits

- This is an early release. Windows/AMD and Linux/X11 have generated-source evidence, but real
  game and device coverage is incomplete. Other graphics cards and physical audio-device recovery
  need more testing. macOS capture is not implemented.
- Wayland's shortcut portal has been tested against a simulated service, not GNOME, KDE, or wlroots.
  The desktop may change shortcuts or refuse some. Direct keyboard-device fallback is off by default.
- Downloads are unsigned. Windows may show a SmartScreen warning. Check downloads against the
  release's SHA256SUMS.txt.
- Optional update checks contact GitHub by default and can be disabled in Settings → General.
- The full network-disabled release test and a clean Windows installer/update/uninstall run remain open.

No media, logs, screenshots, or bug reports are uploaded automatically.
